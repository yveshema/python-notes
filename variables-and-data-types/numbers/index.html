Variables and data types

Programs compute with values, remember them in variables, and combine them in expressions.

In this lesson, we look at:

  • rules of variables
  • how to work with text and numbers
  • some useful built-in functions

Variables

A variable is a name bound to a value with = (assignment). Read x = 5 as "let the name x refer to 5," not "x equals 5".

>>> price = 20
>>> quantity = 3
>>> total = price * quantity
>>> print(total)
60

A variable can be rebound, that is, it can be made to point to a different value, potentially of a different type.

>>> n = 10
>>> n = n + 1
>>> print(n)
11
>>> n = "now text"
>>> print(n)
now text

Right side first

In n = n + 1, Python evaluates n + 1 first, using the current value of n then makes n refer to the result. That is, the right hand side of an assignment statement is always evaluated first.

The value cannot be on the left-hand side of an assignment statement

The following is illegal in Python:

10 = n

The left-hand side of an assignment statement must always be an identifier, a.k.a variable name.

Naming rules & style

  • use letters, digits, and underscores
  • a variable name cannot start with a digit
  • variable names are case-sensitive (total and Total are different names)
  • style: lowercase with_underscores
  • style: descriptive. Prefer tax_rate over tr

Assignment shortcuts

Multiple assignments on one line:

>>> x, y = 1, 2
>>> a = b = 0

Update and rebind:

>>> count = 0
>>> count += 5
>>> count -= 2
>>> print(count)
3

Strings

In Python the type used to represent text is called string. You can use strings to provide feedback to the user during program execution or output logs from the program.

You can generate strings from other strings:

>>> firstname = "Ada"
>>> lastname = "Lovelace"
>>> fullname = firstname + " " + lastname
>>> print(fullname)
Ada Lovelace

You can convert most types to strings:

>>> age = str(25)
>>> print("You are " + age + " years old")
You are 25 years old

Without the str(25) conversion, the print() statement would have produced a TypeError.

Other ways to concatenate (join) strings:

>>> 'Hello' ' world'
'Hello world'
>>> ('Hello'
... ' world')
'Hello world'

Use pairs of triple single or double quotes for multi-line strings:

>>> html = """
<body>
    <h1>About</h1>
</body>
"""

Suppressing newline character in multi-line strings

When printed, the html variable will output a newline character at both ends of the string.

This is often not what you want. Use a \ to suppress a newline character anywhere in the string.

>>> html = """\
... <body>
...     <h1>About</h1>
... </body>"""

The special \ character is used to escape special characters such as quotes, non-printable characters and other characters that have meaning in the language (such as $, parentheses, braces, brackets, ...).

>>> "\"Watch out!\" she cried"
'"Watch out!" she cried'

Raw strings

There are times when you need to output the literal \. You can handle this in two ways:

  • escape the \: path="C:\\Program files\\Python314"
  • use raw strings: path=r"C:\Program files\Python314"

Uppercase and lowercase:

>>> 'python'.upper()
'PYTHON'
>>> 'PYTHON'.lower()
'python'

Get part of a string:

>>> lang = 'python'
>>> lang[0].upper + lang[1:]
'Python'
>>> lang[:-1] + lang[-1].upper()
'pythoN'

Indexing and slicing

lang[0] in the previous example is called indexing. This means retrieving the character at the given position in the string. Strings are sequences and their indexes start from 0.

The expression var[n:m] is called slicing. This means retrieving a substring starting at position n (inclusive) up to position m (exclusive).

Negative index values are permitted and they start at the end of the string.

Expressions & operators

An expression is anything that produces a value. Arithmetic operators:

7 + 2       # ⇒ 9    addition
7 - 2       # ⇒ 5    subtraction
7 * 2       # ⇒ 14   multiplication
7 / 2       # ⇒ 3.5  TRUE division — ALWAYS a float
7 // 2      # ⇒ 3    FLOOR division — drops the remainder
7 % 2       # ⇒ 1    modulo — the remainder
7 ** 2      # ⇒ 49   exponent (7 squared)

Two of these are the beginner surprises worth memorizing:

  • / always gives a float: 4 / 2 is 2.0, not 2.
  • // and % are the integer pair: 17 // 5 is 3, 17 % 5 is 2 — "17 is three fives with 2 left over." % is how you test even/odd (n % 2 == 0) and wrap around (clock arithmetic).

Precedence — the order operations happen

Python follows normal math order: ** first, then * / // %, then + -. Use parentheses whenever you're unsure or want to be clear:

2 + 3 * 4         # ⇒ 14   (multiplication first)
(2 + 3) * 4       # ⇒ 20   (parentheses force the addition first)
2 ** 3 ** 2       # ⇒ 512  (** groups right-to-left: 2 ** 9)

When in doubt, parenthesize. Nobody has ever been confused by too many parentheses; plenty of bugs come from too few.

Converting between types

Text from the keyboard (lesson 04) always arrives as a string, even "25". To do math you must convert. The three converters:

int("25")       # ⇒ 25     string → integer
float("3.5")    # ⇒ 3.5    string → float
str(25)         # ⇒ "25"   number → string
int(3.9)        # ⇒ 3      float → int (truncates toward zero — does NOT round)
float(25)       # ⇒ 25.0

This is the real fix for last week's error:

age = 30
print("age: " + str(age))    # ⇒ age: 30   ✅ convert the number to text

A conversion that doesn't make sense raises ValueError:

int("hello")    # ValueError: invalid literal for int() with base 10: 'hello'
int("3.5")      # ValueError — int() won't parse a decimal string; use float("3.5")

Worked examples

# tip.py — split a restaurant bill
bill = 84.50
tip_rate = 0.18
people = 3

tip = bill * tip_rate           # 15.21
total = bill + tip              # 99.71
per_person = total / people     # 33.236666...

print("Tip:", tip)
print("Total:", total)
print("Each person pays:", per_person)
print("Rounded each:", round(per_person, 2))   # ⇒ 33.24  (round to 2 decimals)

# time_split.py — seconds into minutes and seconds, using // and %
seconds = 200
minutes = seconds // 60         # ⇒ 3
remaining = seconds % 60        # ⇒ 20
print(minutes, "min", remaining, "sec")     # ⇒ 3 min 20 sec

Pitfalls & idioms

  • / vs // — / is float division (5/2 == 2.5), // floors (5//2 == 2). Using // where you meant / silently drops the fraction. The 9/5 in temperature conversion is the classic trap.
  • float is approximate — 0.1 + 0.2 == 0.30000000000000004. Floats can't represent every decimal exactly (they're binary fractions). For money, work in integer cents, or round(...) only for display. Never test floats for exact equality.
  • int("3.5") fails — int() won't parse a decimal string; use float("3.5"), or int(float("3.5")).
  • int(3.9) is 3, not 4 — it truncates toward zero; use round(3.9) to round.
  • Reusing a name for two meanings — once n = "text", n is no longer a number. One name, one meaning.
  • Reading = as "equals" — it's assignment (bind the right side to the left name). Equality is == (lesson 05).

Debugging

When arithmetic gives a surprising answer, print the types: print(type(x), x). Most "wrong number" bugs are really "wrong type" bugs — a value you thought was an int is a str from input (lesson 04), or a // you meant to be /. Seeing the type makes it obvious.
