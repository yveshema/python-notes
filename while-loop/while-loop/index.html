Repeated execution

while — repeat while a condition holds

While loops and if statements have a lot in common. They are both block statements, and they both use conditional evaluation to determine whether the body of the statement runs.

The while loop will repeatedly run its body until the continuation condition becomes false or the loop is interrupted by some other means.

count = 1
while count <= 3:
    print(count)
    count += 1          # ← MUST make progress toward the condition becoming false
print("done")

Two ways to terminate a loop

  • Make the continuation condition false in the loop's body. A while loop checks the continuation condition at the start of each run, meaning that if the condition is false from the start, the loop will never run, not even once. To make the continuation condition false, a controlling variable (count in the previous example) is used and it must be updated in the body of the loop in a way that will make the condition false eventually
  • Using break statement. See next section

The while loop is especially useful when you don't know in advance how many repetitions are required.

answer = ""
while answer != "quit":
    answer = input("Command (or 'quit'): ")
    print(f"you said: {answer}")

break

The following two programs produce the same outcome using different strategies:

count = 0
while count <= 3:
    print(f"{count = }")
    count += 1

count = 0
while True:
    if count > 3:
        break
    print(f"{count = }")
    count += 1

The version with break is particularly useful in infinite loops, which is when the continuation condition cannot become false. This is the "loop until something happens" pattern. Here is another example:

while True:
    cmd = input("> ")
    if cmd == "quit":
        break
    print(f"Running {cmd}"

continue

Sometimes you want to skip the loop's body and jump to the next iteration. The following program prints only odd numbers between 1 and 10:

current = 0
while current <= 10:
    if current % 2 == 0:
        current += 1
        continue
    print(current, " ", end="")
    current += 1
print()

Notice that we update current in two different places. This is a very common source of bugs. If current were not updated before continue, its value would never change and the continuation condition would remain true, leading to an infinite loop.

The else clause

Just like if statements, while loops also can have an option else clause. This clause executes only if the loop terminates normally, meaning when the continuation condition becomes false. If the loop terminates due to a break statement, the else clause is not executed.

password = "secret"
count = 0
while count < 3:
    count += 1
    user_input = input("Enter your password: ")
    if user_input == password:
        print("Access granted!")
        break
    if count < 3:
        print(f"You have {3 - count} attempts left")
else:
    print("Allowed attempts exceeded. Access denied.")

If the user enters the correct password within 3 attempts, the else clause will never be executed.

The accumulator pattern

It is common to carry out computations by accumulating values using a loop. This involves using a controlling variable, but instead of using it just to make the continuation condition false, the variable itself is the computation.

It has the following shape:

  • initialize the variable that will hold the final result
  • loop: each iteration is one step in the computation
  • update the variable with each iteration
  • use after: the computation is completed when the loop terminates

The following program calculates the sum of all even numbers between 0 and 10:

sum = 0
current = 0
while current <= 10:
    if current % 2 == 0:
        sum += current
    current += 1

Here's how to find the largest of some inputs:

biggest = 0
while True:
    user_input = input("Enter a number or 'q' to quit: ")
    if user_input == 'q':
        break
    n = int(user_input)
    if n > biggest:
        biggest = n
print(f"{biggest = }")

Nested loops

Here's how to print a 3 x 3 table of numbers:

row = 1
while row < 4:
    col = 1
    while col < 4:
        print(f"{row * col:3}", end="")
        col += 1
    row += 1
    print()

Again, pay attention to how the controlling variables are initialized. col is initialized inside the outer loop before the inner loop, which essentially means it is re-initialized for each row.

Can you tell what would happen if col had been initialized before the outer loop instead?
